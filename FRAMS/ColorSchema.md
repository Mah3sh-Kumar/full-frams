# FRAMS Color Scheme

This document outlines the official color palette and design tokens used in the FRAMS application.

## Core Palette

### Primary (Indigo)
Used for main actions, active states, and primary branding.
- **Main**: `#4338ca` (Accessible against white)
- **Light**: `#4338ca`
- **Dark**: `#4338ca`
- **Gradient**: `#4f46e5` → `#4338ca`
- **Contrast**: `#ffffff`

### Accent (Cyan)
Used for secondary actions, highlights, and decorative elements.
- **Main**: `#0e7490`
- **Light**: `#0e7490`
- **Dark**: `#155e75`
- **Gradient**: `#0e7490` → `#155e75`
- **Contrast**: `#ffffff`
